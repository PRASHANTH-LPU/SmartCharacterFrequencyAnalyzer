Smart Character Frequency Analyzer

Project Overview

Smart Character Frequency Analyzer is a Java-based console application developed using the HashMap data structure. It analyzes user-entered text and calculates the frequency of each character.

Technologies Used

- Java
- HashMap
- Scanner
- IntelliJ IDEA

Features

1. Character Frequency
2. Unique Characters
3. Repeated Characters
4. Most Frequent Character
5. Character Statistics

Data Structure

HashMap<Character, Integer> is used to store each character as a key and its frequency as a value.

How to Run

1. Download or clone this repository.
2. Open the project in IntelliJ IDEA.
3. Run Main.java.
4. Enter text and select an option from the menu.
